## AMS/Builder

Reference for an assistant agent helping design and review Teamworks AMS Builder work. Start with `manual.md`.

- `AMS/Builder/manual.md`: operating rules, forms, fields, sections, visibility, tables, save buttons, safe changes, testing.
- `AMS/Builder/calculations.md`: calculation types, equation syntax, recipes, linked/history/embedded data, debugging.
- `AMS/Builder/dashboards.md`: Dashboard Builder, widgets, filters, rulesets, customization, printing, troubleshooting.

Keep confidential configurations, athlete data, and internal business information out of this repository.
